Play PEAK with real Minecraft Java movement, HUD, inventory, mining and block placement. The linked mirror world and safe-ground guard fix the repeated Fell out of the world deaths. Esc opens PEAK pause; Minecraft Settings opens the native controls and sensitivity pages. Hold G for boarding; the prompt shows hold progress. Co-op sends blocks, skins and poses through PEAK Photon lobbies, up to four players; use normal PEAK invites and joining menus. Viewer mode is selected with F8. Solo void and loopback sharing were tested, and the creator confirmed the current build runs well. Real two-player joining and late joining remain unverified. Viewer blocks are full cubes; the summit flare is not yet supported. Requires PEAK and a Minecraft Java account. On first launch sign into Minecraft in Prism; the launcher downloads Minecraft, Java and Fabric automatically. No accounts, saves or game files are included.

What's new in 0.2.1: works with more PEAK builds (no more 'Method not found' errors), fewer crashes and freezes (PEAK runs on Direct3D 11 for this mashup, less graphics and network churn, no slow texture loading during level changes), and Minecraft's first-time setup no longer downloads Java: it comes with the mashup.
